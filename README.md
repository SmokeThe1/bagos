# BAGOS

Bale Auto Gift Opener Self
is a small Aiobale project for bale.

Bagos is a project built with  [`aiobale-py`](https://github.com/aminmadaniofficial/aiobale) that open the gifts automatically in bale massenger

its so simple just run the project and login to bale and BAGOS  open the gifts automatically


> This project is for educational and personal use. Please use it responsibly and respect Bale's rules and rate limits.

---

## Requirements

you need:

- Python 3.8+
    
- Git
    
- A Bale account

---

## 1. Fork the repository

**[https://github.com/SmokeThe1/bagos](https://github.com/SmokeThe1/bagos)**

open and fork this repository

---

## Clone your fork

Clone your repository:

```bash
git clone https://github.com/YOUR_USERNAME/bagos.git
cd bagos
```

Replace `YOUR_USERNAME` with your GitHub username.

---

## 3. Create a virtual environment

It's recommended to use a virtual environment so the project's Python dependencies stay isolated.

On Windows:

```bash
python -m venv .venv
```

Activate it:

```bash
.venv\Scripts\activate
```

For PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

You should see something similar to this in your terminal:

```text
(.venv)
```

---

## 4. Install Aiobale

Install the package with:

```bash
pip install aiobale-py

```

---

## 5. Run Bagos

Once everything is installed, run the project.

If the main file is `main.py`:

```bash
python main.py
```

If the project uses another entry point, run that file instead.

On the first run, Aiobale may ask you to authenticate your Bale account.

> [!NOTE]
> On the second and subsequent runs, the program may say that it is connecting to Bale, or it may not show anything at all. Don't worry — this is normal, and the program is still working.
